PART 3
The scenarios
THE PRODUCTOne chat box. Every answer shows its plan, its steps, and their timings.
SINGLE SERVICE“What’s on my calendar next week?” — live steps first, then the week, from the mirror, in the user’s timezone
SINGLE SERVICE“Find emails from sarah@company.com about the budget” — hybrid search: vector similarity + sender filter
SINGLE SERVICE“Show me PDFs in Drive from last month” — mime filter + date window, and the answer states the window it searched
MULTI-SERVICE“Cancel my Turkish Airlines flight” — booking found, PNR ABC123 extracted, cancellation drafted, send gated behind approval
MULTI-SERVICE“Prepare for tomorrow’s meeting with Acme Corp” — event + mail + Drive in parallel, one briefing
MULTI-SERVICE“Find events next week that conflict with my out-of-office doc” — the doc’s dates drive the calendar check
HARD CASE“Move the meeting with John” — which John, which meeting? His real meetings become choices, not guesses
HARD CASEOne tap picks the meeting; only the genuinely unknowable thing — the new time — is asked, as a typed date field
HARD CASETurn one: “Summarise the Acme Corp proposal email”
HARD CASETurn two: “Who sent that email about the proposal?” — “that email” resolves from conversation context
HARD CASE“What’s on my calendar next Tuesday?” — temporal reasoning, timezone-aware: Tuesday the 25th, one event
WRITE FLOW“Compose an email… write a good subject and body yourself” — drafted into Gmail; nothing has been sent
WRITE FLOW“Send it” — the draft is found in context, the send is staged, and the approval card names the recipient
